## 1. 처음 시작하기

1. [릴리스 페이지](https://github.com/justkevin2570-hash/SSNnote/releases/latest)에서 `SSNnote_Setup.exe`를 받아 설치합니다.
2. 바탕화면에 노란 메모장이 뜹니다. 맨 위 **업무명** 칸에 할 일을 쓰고 **Enter**를 누르면 업무가 추가됩니다.
3. 마감일이 있으면 업무명 아래 **마감일** 칸에서 날짜(필요하면 시각)를 고른 뒤 Enter를 누르세요.
4. 앱을 닫아도 작업 표시줄 오른쪽 **트레이 아이콘**으로 계속 실행됩니다. 완전히 끄려면 트레이 아이콘 → **종료**.

> 다른 창에서 일하다가 **Ctrl+Shift+E**를 누르면 서서니 노트가 바로 앞으로 나옵니다.

## 2. 화면 구성

**제목 표시줄 (맨 위)** — 왼쪽에 「서서니 노트」와 오늘 날짜가 보입니다.

| 버튼 | 하는 일 |
|---|---|
| 말풍선 AI | AI 대화 창 열기/숨기기 (열려 있으면 버튼 바탕이 칠해짐) ([AI 대화](#ai-대화-업무창-옆)) |
| ₩ | 예산 관리 창 열기 |
| 메모 연필 | 메모 모드 ↔ 업무 모드 전환 (메모 모드일 때 바탕이 칠해짐) |
| … | 메뉴 |
| 핀 | 항상 화면 위에 고정 켜기/끄기 (Ctrl+Shift+F, 켜지면 핀이 채워짐) |
| ✕ | 메모장 닫기 (앱은 트레이에서 계속 실행) |

**업무 추가 칸** — 평소엔 「＋ 업무 추가」 한 줄만 보입니다. 누르거나 글자를 쓰면 그 아래에 마감일·시각·반복(반복 없음·매주·격주·매월·매년·사용자 설정) 칸이 나타납니다.

**업무 목록** — 별(중요), 업무명, 메모 아이콘(메모가 있을 때), D-day, ⋮(업무 메뉴)
- ⋮ 버튼과 메모 쓰기 아이콘, 「＋날짜」는 **업무 줄에 마우스를 올리거나 선택했을 때만** 보입니다.
- 굵은 글씨는 중요 표시(★)한 업무입니다.
- 칸 테두리, 선택한 줄, 스크롤바 색은 **메모 바탕색에 맞춰** 자동으로 정해집니다(메뉴 → 배경색·글자 크기).

**아래쪽 버튼**

| 버튼 | 하는 일 |
|---|---|
| 달력 | 월간 달력 (모든 메모장의 마감 업무) |
| 공문 작성 | 공문 작성 창 (AI 초안·공문 캡처) |
| 지난 기록 | 두 칸으로 된 창. **지난 업무**: 삭제한 업무를 마감 달별로 보고 되살리기(마감이 지나지 않은 업무만) · **작성 공문**: 공문 작성 창에서 저장한 공문 (제목·본문 복사, **수정**: 제목·공문번호·본문을 고쳐 [저장]. 고치는 중에는 목록이 잠기고 [취소]로 되돌릴 수 있음). 처음엔 지난 업무, 그다음부터는 마지막에 본 칸이 열림 |

## 3. 업무 관리

### 업무 추가
- **「＋ 업무 추가」** 칸에 쓰고 **Enter**. **Tab**을 누르면 마감일(오늘로 채워짐) → 시각 → 반복 칸으로 차례로 이동합니다.
- 마감일을 비워 두면 날짜 없는 업무가 됩니다. 나중에 업무 줄의 **「+날짜」**를 눌러 넣을 수 있습니다.
- **반복**을 고르면 마감이 지난 다음 날 자동으로 다음 마감일로 넘어갑니다. 「사용자 설정…」으로 "매월 둘째 주 화요일" 같은 반복도 만들 수 있습니다.

### 업무 다루기

| 하고 싶은 일 | 방법 |
|---|---|
| 업무명 고치기 | 업무를 더블 클릭, 또는 선택하고 **F2** |
| 업무 사이 이동 | 업무를 선택하고 **↑ / ↓** |
| 업무 메모 열기 | 업무를 선택하고 **Enter**, 또는 업무명 옆 메모 아이콘 (메모가 없으면 줄에 마우스를 올리면 나오는 연필 아이콘) |
| 메모 닫기 | 메모 칸에서 **Esc** 또는 **Ctrl+Enter** |
| 중요 표시 | 업무 앞 **☆**를 눌러 ★로 |
| 완료 표시 (가운데 선) | ⋮ 메뉴 → 완료 표시 (메뉴를 연 상태에서 **C**) |
| 삭제 | ⋮ 메뉴 → 삭제 (메뉴를 연 상태에서 **Delete** / **D**). 지난 기록에 남음 |
| 반복 바꾸기 | ⋮ 메뉴의 **반복** 줄에서 없음·매주·격주·매월·매년·직접… 중 하나를 누름 (지금 반복은 진하게 표시) |

### 업무 메모
업무를 펼치면 아래에 메모 칸이 열립니다.
- **메모** — 자유롭게 적습니다.
- **관련 공문번호** — 직접 쓰거나 **[스크린샷]**을 눌러 화면의 공문번호를 찍으면 글자로 읽어 넣습니다. **[복사]**로 복사합니다.
- **붙임파일** — 파일을 업무 줄로 끌어다 놓으면 붙습니다. 누르면 파일이 열립니다.

### AI 대화 (업무창 옆)
업무창 오른쪽(또는 아래쪽)에 붙는 **AI 대화 창**에서 업무를 묻거나 시킬 수 있습니다. 처음에는 열려 있습니다.
- **열기·숨기기** — 업무창 제목줄의 **말풍선 「AI」** 버튼, 또는 AI 창 오른쪽 위 **✕**. 「…」 메뉴와 빠른 찾기(Ctrl+K)에도 있습니다.
- **붙는 위치** — AI 창의 **⋯** → 오른쪽에 붙이기 / 아래쪽에 붙이기. 화면 끝이면 반대쪽(왼쪽·위)에 붙습니다. 바깥쪽 가장자리를 끌어 폭(높이)을 바꿉니다.
- **물어보기** — "이번 주 마감 알려줘"처럼 묻거나 아래 **[오늘 할 일] [이번 주 마감] [급한 순서]**를 누릅니다. 모든 업무창의 업무를 보고 답합니다.
- **시키기** — "다음 주 금요일까지 공문 회신 추가해줘", "협의회 자료 마감을 수요일 3시로 바꿔줘", "OO 완료 표시해줘", "OO 중요 표시해줘". AI가 바꿀 내용을 보여 주면 **[넣기]**를 눌러야 반영되고, 넣은 뒤 **되돌리기**를 한 번 누를 수 있습니다. 새 업무는 AI 창이 붙어 있는 업무창에 들어갑니다.
- 업무 **삭제**는 AI가 하지 않습니다 (업무 줄 ⋮ 메뉴에서 지우세요). 날짜가 이상하거나 없는 업무를 가리키는 제안은 회색으로 보이고 넣을 수 없습니다.
- AI 연결은 AI 창 위쪽 상태 버튼(공문 작성·예산 창과 같은 설정)에서 바꿉니다.

### D-day 표시
마감까지 남은 날을 둥근 표시로 보여주고, 급한 정도에 따라 색이 다릅니다. 마우스를 올리면 날짜가, 누르면 마감일 바꾸기가 나옵니다.

| 표시 | 뜻 |
|---|---|
| 빨간 바탕 `D+2 지남` | 기한이 지남 |
| 주황 바탕 `D-day` / `3시간` | 오늘 마감 |
| 옅은 주황 `D-2` | 1~3일 남음 |
| 옅은 호박색 `D-5` | 4~7일 남음 |
| 회색 글자 `D-20` | 그 뒤 |

### 급한 업무 움직임
마감 5일 전부터 업무 **줄 왼쪽에 세로선**이 생겨 숨쉬듯 나타났다 사라집니다. 평소에는 아무것도 움직이지 않고, D-day 표시도 움직이지 않고 색으로만 알려줍니다.

| 상황 | 표시 |
|---|---|
| 마감 4~5일 전 | 주황 세로선이 천천히 숨쉼 (6초) |
| 마감 3일 전 ~ 당일 | 주황 세로선이 숨쉼 (3초) |
| 마감 3시간 전 (시각이 있는 업무) | D-day 자리에 **남은 시간**(`2시간 47분`), 줄 아래 막대가 차오름 |
| ★ 중요 업무 | 세로선이 금색이고, **★ 별도 같은 박자로** 나타났다 사라짐. 기한을 놓치면 빨간 테두리 별 |
| 기한 지남 | 움직이지 않음 — 빨간 `D+n 지남` 표시로 알림 |

- 제목 줄에 **`지남 1 · 오늘 2`** 배지가 생겨 메모 창을 접어 둬도 급한 업무가 있는지 보입니다.
- 완료 표시(C)를 하면 가운데 선이 그어지고 움직임이 멈춥니다. ★를 누르면 별이 톡 커지고 업무가 맨 위로 미끄러져 올라갑니다.
- **설정:** 메뉴 → 설정 → **급함 표시 (움직임)**
  - **움직임 켜기** — 끄면 색 표시만 남습니다(남은 시간 표시도 꺼짐).
  - **남은 시간 표시** — 끄기 / 1시간 전부터 / 3시간 전부터(기본) / 6시간 전부터
- 색 표시(빨강·주황·옅은 주황 등)는 설정과 상관없이 그대로입니다. 메모 창이 가려져 있으면 움직임도 쉬어서 컴퓨터에 부담을 주지 않습니다.

## 4. 마감 알림

메뉴 **설정 → 마감 알림**에서 고릅니다.
- **D-day 5일 이내 알림** — 마감 5일 이내 업무를 정해진 간격(30분 / 1시간 / 3시간 / 사용자 설정)마다 알려줍니다. 「사용 안 함」으로 끌 수 있습니다.
- **당일 마감 3시간 전부터 알림** — 시각이 있는 오늘 마감 업무를 3시간·2시간·1시간·30분 전에 알려줍니다.

알림은 화면 오른쪽 아래에 유주와 함께 10초 동안 뜹니다.
- 급한 업무가 위로 오고, 오른쪽 표시 색이 급한 정도를 알려 줍니다: **빨강** 오늘·몇 시간 안 / **주황** D-1·D-2 / **노랑** D-3~5. 4건이 넘으면 「외 n건 더」.
- 유주 표정도 급한 정도에 따라 바뀝니다.
- 마우스를 올려 두면 사라지지 않고 기다립니다(아래 시간 막대가 멈춤). 클릭하거나 ×를 누르면 바로 닫힙니다.
- 유주의 흔들림은 **급함 표시 → 움직임 켜기**를 끄면 함께 꺼집니다.

## 5. 오늘 한눈에 보기

메뉴 **오늘 한눈에 보기**. 하루 한 번 앱을 켤 때 자동으로도 뜹니다(창 아래 체크로 끌 수 있음).
- 위쪽 세 칸: 지난 마감 · 오늘 마감 · 이번 주(7일) 개수 (글자는 칸의 가운데). 지난 마감·오늘 마감이 1건 이상이면 칸에 색이 깔립니다.
- 한 줄 요약, 그 아래 급한 업무 목록 — 누르면 해당 메모장에서 그 업무가 반짝 강조됩니다.
- 예산 집행률 (예산을 등록한 경우). 80% 이상이면 주황, 100% 이상이면 빨강이고, [예산 창 열기 ›]로 바로 갈 수 있습니다.

## 6. 빠른 찾기 (Ctrl+K)

기능과 업무를 이름으로 찾아 바로 엽니다.
- **초성 검색**이 됩니다: `ㅇㅅ` → 예산 관리, `ㄱㅁㅎㅇ` → 교무회의 자료 제출
- 띄어쓰기는 무시하고, 영어(budget, capture …)로도 찾을 수 있습니다.
- **↑↓**로 고르고 **Enter**로 실행, **Esc**로 닫기.
- 업무를 고르면 해당 메모장에서 그 업무를 강조합니다.

---

## 7. 달력

아래쪽 **[달력]** 버튼.
- 모든 메모장의 마감 업무를 날짜 칸에 보여줍니다. 오른쪽 위 **‹ ›**로 달을 넘기고 **[오늘]**로 돌아옵니다.
- 오늘은 빨간 동그라미, 중요 표시한 업무는 주황 점, 완료 표시한 업무는 옅은 가운데 선으로 보입니다.
- 칸에 다 안 들어가면 **「+N개 더」**가 나옵니다. 날짜를 누르면 그날 업무를 모두 보고 **편집(연필) / 삭제(휴지통)**, **[+ 할 일 추가]**를 할 수 있습니다.
- 달력은 다른 창 위에 고정되지 않는 보통 창입니다. **Esc**를 누르면 닫힙니다.

## 8. 메모 모드와 여러 메모장

- **메모 모드** — 제목 표시줄의 ✏️ 버튼을 누르면 업무 목록 대신 자유 메모장이 됩니다. 한 번 더 누르면 돌아옵니다.
- **새 메모장** — 메뉴 → 새 메모장. 회의 메모, 연락처처럼 따로 두고 싶은 내용에 좋습니다. 새 메모장은 **메모만** 쓰는 단순한 창이라, 메뉴(⋯)에는 **배경색·글자 크기 · 다크 모드 · 메모장 삭제** 세 가지뿐이고 단축키도 없습니다.
- **꾸미기** — 메뉴 → **배경색·글자 크기** → 배경색 / 글자 크기 (이 메모장에만 적용. 줄 간격은 첫 메모장의 업무 목록에만 있음)
- **창 붙이기** — 메모장을 다른 메모장 옆으로 끌면 자석처럼 붙습니다. 나란히 붙었을 때 나타나는 버튼을 누르면 하나처럼 함께 움직이게 묶이고, 다시 누르면 풀립니다.
- **접기** — 첫 메모장은 **Ctrl+Shift+R**(또는 제목 표시줄 더블클릭)로 제목 표시줄만 남기고 접습니다. 한 번 더 하면 펼쳐집니다. 새 메모장은 제목 표시줄 더블클릭만 됩니다.
- **메모장 삭제** — 메뉴 → 메모장 삭제 (첫 메모장은 지울 수 없음). 그 메모장의 업무도 함께 지워집니다.

## 9. AI 연결 (API 키)

공문 캡처, 자동 초안, 공문 작성 창의 AI 대화, 예산 창의 'AI에게 묻기', 업무창 옆 AI 대화에 쓸 AI를 고릅니다.
메뉴 **설정 → AI 연결 (API 키)…** (공문 작성 창·예산 창·AI 대화 창 위쪽의 **AI 상태 버튼**과 같음)

지원하는 AI는 네 가지입니다. OpenCode·Claude·ChatGPT는 API 키를 받아 넣고 쓴 만큼 요금이 나가며 공문 한 건은 보통 몇 원 수준입니다. **Claude 구독**은 API 키 없이 가지고 계신 Claude Pro/Max 구독으로 씁니다 ([아래 절](#claude-구독으로-ai-쓰기)).

| AI | 필요한 것 | 키 받는 곳 |
|---|---|---|
| **OpenCode** | OpenCode Go(월 구독) 또는 Zen(충전식) | opencode.ai → 콘솔 → API Keys |
| **Claude** | Anthropic API 키 (Claude 구독과 별도) | console.anthropic.com → API Keys |
| **ChatGPT** | OpenAI API 키 (ChatGPT 구독과 별도) | platform.openai.com → API keys |
| **Claude 구독** | Claude Pro 또는 Max 구독 (API 키 없음, 이 PC에 Claude Code 설치) | 설정 창의 [설치] · [Claude로 로그인] |

> 예전 버전에서 Gemini·NVIDIA·내부 AI(Ollama)를 쓰셨다면 AI가 꺼진 상태로 바뀝니다. 공문 작성 창 위의 **[AI 다시 연결 필요]**를 눌러 하나를 연결하세요.

### 연결 순서 (OpenCode·Claude·ChatGPT)
1. AI를 고릅니다. OpenCode는 먼저 요금제(**Go** 또는 **Zen**)를 고릅니다.
2. **API 키** 입력 — 「이 PC에 키 저장」을 끄면 앱을 끌 때 지워집니다(공용 PC 권장). 눈 모양 버튼으로 입력한 키를 확인할 수 있습니다.
3. **모델 선택** — 그 회사에서 받은 **최신 목록**이 나옵니다(목록을 못 받으면 기본 목록).
   - Claude·ChatGPT는 목록 위쪽이 최신 모델입니다. 공문 작성에는 빠르고 저렴한 모델(Claude **claude-haiku-5-5**, ChatGPT **gpt-5.4-mini**)로 충분합니다.
   - OpenCode는 **claude-haiku-5-5**가 기본값이자 추천입니다(빠르고 저렴, 서식을 잘 지킴, 학습에 쓰지 않음, 30일 보관).
   - **🖼 이미지** 표시가 있는 OpenCode 모델은 캡처한 공문 이미지도 직접 읽습니다.
   - **⚠ 지역 설정 필요**(DeepSeek) — OpenCode 기본 설정(유럽·미국)에서는 막혀 있습니다. 쓰지 않는 것을 권장합니다.
4. 자동으로 **연결 확인**을 합니다. 성공하면 키·모델이 저장되고 공문 작성 창 위에 「OpenCode · claude-haiku-5-5」처럼 표시됩니다. 실패하면 이유(키 오류, 잔액 부족, 사용 한도 등)를 알려주고 **설정을 바꾸지 않습니다**.

### Claude 구독으로 AI 쓰기

Pro 또는 Max 구독이 있으면 API 키 없이 쓸 수 있습니다. 이 PC에 설치된 공식 **Claude Code**를 서서니 노트가 대신 실행합니다.

> **사용량 안내**: 구독 사용량에서 차감됩니다 (Claude 채팅·Claude Code와 같은 한도). **본인만 사용하세요.**
> **로그인 정보**: 로그인은 Claude Code가 자기 자리에 보관합니다. 서서니 노트는 로그인 정보를 저장하지 않습니다. 토큰도 읽지 않습니다.

1. **설정 → AI 연결 → Claude 구독** (공문 작성 창의 AI 상태 버튼)을 누릅니다.
2. **[설치]**: Claude Code가 없으면 공식 설치 명령을 숨김 창에서 실행합니다. 1~2분 걸릴 수 있어요. 안 되면 창에 있는 공식 설치 안내 주소를 보세요.
3. **[Claude로 로그인]**: 브라우저가 열리면 Claude 공식 페이지에서 로그인하고 승인하세요. 끝나면 창의 상태가 「✓ 로그인됨 (이메일 · Pro 구독)」으로 바뀝니다. 로그아웃은 같은 자리의 [로그아웃]입니다.
4. **모델**: 기본 모델을 그대로 두거나 Sonnet·Opus·Haiku 중 고릅니다.
5. **[연결 확인]**: 짧은 질문을 한 번 보내 성공 여부와 걸린 시간을 보여 줍니다. 성공하면 **[저장]**을 누르세요. 로그인이 안 된 상태에서는 저장되지 않습니다.

- `claude` 실행 파일을 자동으로 못 찾으면 창 아래 칸에 경로를 직접 적습니다. 비워 두면 자동으로 찾습니다.
- 사용 한도에 걸리면 「구독 사용 한도에 도달했어요」라고 알려 줍니다. 잠시 뒤 다시 시도하세요.
- 캡처한 공문 이미지는 보내지 않고, PC에서 읽은 글자만 보냅니다.
- 개인정보 보호 모드를 따릅니다 (켜져 있으면 가려서 보냄).
- 정책이 바뀌어 구독 방식을 쓸 수 없게 되면 API 키 방식(Claude·ChatGPT·OpenCode)으로 바로 바꿀 수 있습니다.

AI를 끄려면 같은 메뉴에서 **AI 끄기**. 꺼져 있어도 자동 초안은 공문 뼈대를 넣어 줍니다.

## 10. 공문 캡처 (Ctrl+Shift+X)

받은 공문을 화면에서 캡처하면 AI가 읽고 정리해 줍니다. **제목·공문번호는 공문 작성 칸(오른쪽)에, 요약은 왼쪽 「받은 공문」 칸**에 들어가므로 그대로 공문을 쓰면 됩니다. (먼저 [AI 연결](#9-ai-연결-api-키)이 필요합니다.)

1. 공문 화면을 띄우고 **Ctrl+Shift+X** (또는 메뉴 → 공문 캡처, 공문 작성 창 위의 **[공문 캡처]**)
2. 마우스로 공문 부분을 드래그합니다.
3. 공문 작성 창이 열리고(이미 열려 있으면 그 창), 아래처럼 채워집니다. 틀린 곳은 고칠 수 있습니다.
   - 오른쪽 **제목** ← 받은 공문 제목
   - 오른쪽 **관련 번호** ← 공문번호. 날짜까지 공문 양식대로: `중등교육과-12345(2026. 11. 3.)` (기관명은 빼고, 날짜는 시행일)
   - 왼쪽 **요약** ← 핵심 내용, 기한
   - 찾은 것만 넣습니다. 제목·관련 번호 칸을 직접 고쳤으면 그대로 둡니다.
4. 필요한 버튼을 누릅니다.
   - 왼쪽 **[요약 복사]** — 「제목 (관련 번호)」와 요약을 함께 복사 (메신저·회의 공유용)
   - 아래 **[제목 복사] [관련번호 복사] [본문 복사]** — 업무관리시스템에 붙여 넣기용
5. 오른쪽 AI 대화와 자동 초안은 받은 공문의 요약을 함께 보고 씁니다(예: "이 공문 기준으로 제출 공문 써줘").

### 두 번 나눠 캡처하기 (이어서 캡처)

제목·본문과 공문번호가 한 화면에 안 잡히면 **두 번 캡처**하세요. 공문 작성 창에서는 다시 캡처해도 앞 내용이 지워지지 않고 **같은 공문에 덧붙습니다**.

1. 첫 번째: 제목·본문 부분 캡처 → 제목과 요약이 채워집니다. 공문번호를 못 찾으면 「번호 부분만 한 번 더 캡처하세요」라고 알려줍니다.
2. 두 번째: 공문번호(날짜) 부분 캡처 → 두 캡처를 **합쳐서 다시 분석**하고, 비어 있던 관련 번호 칸이 채워집니다. 칸 위에 캡처 그림이 1, 2 순서로 보입니다.

- 새 결과에 없는 내용(예: 번호만 찍은 캡처의 제목)은 앞 내용을 그대로 둡니다.
- **직접 고친 요약은 다시 분석해도 덮어쓰지 않습니다.** 오른쪽 제목·관련 번호 칸도 직접 고쳤으면 그대로 둡니다.
- 한 공문에 캡처는 4장까지 모읍니다(넘으면 가장 먼저 찍은 것을 뺍니다).
- **다른 공문**을 캡처하려면 왼쪽 칸 위의 **[+ 새 공문]**을 누르거나, 창을 닫았다가 다시 여세요.
- 두 번째 캡처부터는 합친 내용으로 AI에 한 번 더 요청합니다(공문 한 건에 몇 원 수준).

> 칸은 « 버튼으로 접고, 창 위의 [받은 공문]으로 다시 펼칩니다.
> AI가 꺼져 있으면 글자만 읽어 공문번호 모양이면 관련 번호 칸, 아니면 제목 칸에 넣습니다.
> AI가 실패하면 다시 캡처하거나, 제목·관련 번호·요약을 직접 적어도 됩니다.

## 11. 공문 작성 (AI)

아래쪽 **[공문 작성]** 버튼.

| 칸·버튼 | 하는 일 |
|---|---|
| 공문 캡처 (위) | 받은 공문을 캡처 → 제목·관련 번호는 오른쪽 칸, 요약은 왼쪽 「받은 공문」 칸 ([10장](#10-공문-캡처-ctrlshiftx)) |
| AI 상태 (오른쪽 위) | 지금 쓰는 AI와 모델 (예: 「OpenCode · claude-haiku-5-5」). 누르면 AI를 바꾸거나 끔 |
| ? (오른쪽 위) | 사용 방법 |
| 제목 | 제목을 쓰고 **Enter** → 자동 초안 생성 |
| 관련 번호 | 관련 공문번호. ↑ 버튼은 이 칸의 글을 제목으로 옮김 |
| 붙임 | 초안의 붙임 줄 개수 (0 = 붙임 없음) |
| 공문 종류 (자동 초안 옆) | 제목으로 판별한 공문 종류(결과 보고·제출·품의/지출 등). 키워드가 없어 「일반 계획/운영」으로 정해지면 흐리게 보임. 눌러서 직접 고르기 / 「자동」으로 되돌리기 |
| 자동 초안 생성 | 고른 공문 종류에 맞는 뼈대를 넣고 AI가 내용을 채움. 본문에 쓴 글이 있으면 바꾸기 전에 물어봄 |
| AI에게 요청 (아래 칸) | "장소를 시청각실로 바꿔줘"처럼 요청 → AI가 본문을 고침. **Enter** 보내기, **Shift+Enter** 줄바꿈, **Esc** 취소 |
| 제목 복사 / 관련번호 복사 / 본문 복사 | 업무관리시스템에 붙여 넣기용 |
| 저장 후 나가기 | 공문을 **지난 기록 → 작성 공문**에 남기고 닫기 |

- AI가 고친 뒤 **Ctrl+Z**를 누르면 이전 내용으로 돌아갑니다(**Ctrl+Y**로 다시 AI 결과).
- AI 오류·빈 답·취소 때는 작성 중이던 내용이 그대로 남습니다. 자동 초안이었다면 뼈대만 들어가고, Ctrl+Z로 원래 글로 돌아갑니다.
- AI 대화는 본문을 AI 답으로 **바꿉니다**. 질문만 하고 싶을 때는 Ctrl+Z로 되돌리세요.

### 내 스타일로 쓰게 하기

- **저장한 공문을 예시로**: **[저장 후 나가기]**로 저장한 공문 중 제목이 비슷한 것 최대 2개를 자동 초안 때 AI에게 예시로 보냅니다. 비슷한 게 없으면 같은 종류의 최근 공문을 보냅니다. AI는 말투·항목 구성은 따르고 날짜·장소 같은 내용은 새로 씁니다. **다듬어서 저장할수록 더 닮아 갑니다.**
- **나만의 작성 규칙**: **[AI 설정] → 나만의 작성 규칙…**에 꼭 지킬 규칙을 적어 두면(예: "대상은 '전교생' 대신 '1~3학년 전체 학생'으로") 자동 초안·AI 대화 때마다 함께 보냅니다. Claude 앱 연결로 공문을 쓸 때도 이 규칙을 따릅니다.
- 상태줄에 「내 공문 2개 · 작성 규칙 참고」처럼 무엇을 참고했는지 보입니다.
- 예시 공문과 규칙도 AI로 보내는 글이라 **개인정보 보호 모드**의 가리기를 똑같이 거칩니다.

### 공문 선택 부분 다듬기

본문 일부만 문장을 고치고 싶을 때 씁니다.

1. 고칠 글을 드래그로 선택하고 **우클릭 → 선택 부분 다듬기**. 선택이 없으면 본문 전체를 다듬습니다.
2. AI가 공문 문체(개조식, 「~함」·「~바람」)로 다듬습니다. 의미·수치·날짜·장소는 바꾸지 않도록 지시하며, 내 작성 규칙과 비슷한 예시 공문을 함께 보냅니다.
3. **비교 창**이 열립니다. 왼쪽은 원문, 오른쪽은 다듬은 글입니다. 바뀐 단어는 색으로 표시되고, 오른쪽 글은 직접 고칠 수 있습니다.
4. **[적용]**(Enter)을 누르면 선택한 부분만 바뀝니다. **[취소]**를 누르면 본문은 그대로입니다.

- 적용한 뒤 **Ctrl+Z 한 번**이면 원래 글로 돌아갑니다. 상태 줄의 **[되돌리기]** 링크도 같은 일을 합니다.
- 다듬는 동안 본문은 잠기고, **Esc**로 멈출 수 있습니다 (본문은 그대로).
- 개인정보 보호 모드가 켜져 있으면 가려서 보내고, 답이 오면 가린 부분을 원래 값으로 되돌립니다. 되돌릴 수 없으면 적용하지 않고 알려 줍니다.
- AI 연결이 꺼져 있으면 쓸 수 없습니다.

## 12. 개인정보 보호

- **개인정보 보호 모드** (기본 켬, 메뉴 **설정 → 개인정보 보호 모드**로 켜고 끔) — AI로 보내기 전에 아래를 가립니다.
  - **주민등록번호** (`080512-3******`, 하이픈 없이 붙여 쓴 것도)
  - **전화번호** (휴대폰·일반전화, `010-****-5678`, 붙여 쓴 번호와 `+82` 번호도)
  - **이메일**, **계좌번호**(숫자 묶음을 하이픈으로 이은 10자리 이상), **아파트 동·호수**(`○○○동 ○○○호`)
  - **생년월일** — '생년월일', '생일', '출생' 뒤의 날짜
  - **이름** — 「홍길동 학생」, 「3반 5번 홍길동」, 「보호자: 홍길동」처럼 **이름이 분명한 자리**의 이름 (`홍○○`)
  - 캡처한 공문은 이미지 대신 **PC에서 읽은 글자만** 보냅니다.
  - **Claude 연결**(아래)로 Claude 앱이 업무 목록을 볼 때도 업무 이름·메모의 개인정보를 가려서 보여줍니다. 가려진 글로 덮어쓰는 수정은 막습니다.
  - **한계:** 문맥이 없는 이름(예: 문장 중간의 「철수가 ~」)과 주소(도로명)는 가리지 못합니다. 학생 명단이 들어간 공문은 보내기 전에 한 번 더 확인하세요.

## 13. Claude 연결

Claude 구독(Pro·Max)이 있으면, **Claude 앱에서** 서서니 노트의 업무를 보고 추가하고 공문 초안을 쓸 수 있습니다. API 키는 필요 없습니다.

1. Claude 데스크톱 앱이나 Claude Code를 설치하고 로그인합니다.
2. 메뉴 **설정 → Claude 연결…** → 쓰는 쪽의 **[연결]**
3. Claude 데스크톱 앱은 **완전히 종료(트레이 아이콘 오른쪽 클릭 → 종료)했다가 다시 켜면** 적용됩니다.
4. Claude 앱 **설정 → 개발자**에 **ssnnote**가 보이면 준비 끝. 새 대화에서 아래처럼 말하면 되고, 처음 한 번은 도구 사용을 **허용**해 주세요.

Claude에게 이렇게 말해 보세요.
- "오늘 할 일 정리해줘", "이번 주 마감 뭐 있어?"
- "다음 주 금요일 5시까지 교과협의회 계획서 제출, 업무로 넣어줘"
- "교무회의 자료 제출 완료 처리해줘"
- "학교폭력 실태조사 결과 보고 공문 초안 써줘"

추가·수정한 업무는 켜져 있는 메모장에 3초 안에 나타납니다. Claude는 업무를 **삭제할 수 없습니다**(실수 방지).

> Claude 앱에 공문 캡처 이미지를 붙여 넣고 "이 공문 업무로 등록해줘"라고 해도 됩니다.

**안 될 때** — 「Claude 연결」 창의 데스크톱 앱 줄 아래에 Claude가 서서니 노트를 마지막으로 쓴 시각이 나옵니다. 기록이 없으면 Claude 앱을 트레이까지 완전히 종료했다가 다시 켜 보고, 그래도 안 되면 **[연결 진단]**을 눌러 나온 내용을 복사해 보내 주세요(연결 프로그램 직접 실행 결과, Claude 앱 설정 파일·기록을 모아 줍니다).

자세한 내용: [Claude 연결 방법](../Claude_연결_방법.md)

## 14. 예산 관리

제목 표시줄의 **₩** 버튼.

| 화면 | 하는 일 |
|---|---|
| 위 요약 | 예산현액 · 집행액 · 잔액 · 집행률 (잔액이 마이너스면 빨강) |
| 왼쪽 세부항목 목록 | **전체** 또는 세부항목 하나만 보기. 항목마다 집행률 막대와 잔액 |
| 오른쪽 표 | 세부항목별 표. **집행액 칸을 누르면 바로 고치고 Enter**로 저장 |
| 원가통계비목 칩 | 세부항목 이름 아래에 비목별 **잔액·집행률**. 누르면 그 비목의 줄만 보기(다시 누르면 전부). **전체**를 고르면 맨 위에 세부항목을 가리지 않고 비목끼리 합친 「원가통계비목별 합계」 |
| 줄 오른쪽 [수정] [완료] | **수정**: 항목 고치기 · 이번에 쓴 금액 넣기 · 오른쪽 위 **[삭제]** / **완료**: 다 쓴 항목 표시 (완료한 줄은 [완료 취소]) |
| [수정] → **이번에 쓴 금액** | 이번에 쓴 돈만 적으면 집행액에 더해지고 잔액이 줄어듦 (바뀔 금액을 바로 보여 줌). **쓴 곳**(예: 체육대회 협의회비)과 **날짜**도 함께 적으면 사용 내역에 남습니다. 집행액 칸은 잘못 넣은 값을 바로잡을 때 직접 고침 (사용 내역은 남지 않음) |
| 산출내역 칸의 **▸** | 누르면 아래 줄에 사용 내역(날짜 · 쓴 곳 · 금액)이 펼쳐짐. 쓴 곳을 적지 않은 금액과 **명목 없음** 금액도 보임. 기록 옆 **✕**로 한 건 지우면 집행액도 줄어듦. 기록이 5건을 넘으면 **더 보기** |
| ▾ 완료 n건 | 완료한 항목은 흐리게(취소선) 표 아래에 모여 보임. 눌러서 접기·펼치기 |
| [가져오기] | 엑셀 파일 열기 · 붙여넣기(엑셀 표 또는 캡처 이미지) |
| **[세부항목 관리]** | 세부항목 추가 · 이름 바꾸기 · 삭제 |
| 세부항목 옆 **+** | 그 세부항목에 항목 직접 추가 (표 위에서 우클릭 → 항목 추가…도 됩니다) |
| 세부항목 옆 **휴지통** | 그 세부항목을 지웁니다. 안의 항목과 사용 내역도 함께 지워지므로, 확인창에서 항목 수와 집행액을 보고 한 번 더 확인하세요 |
| [⋯] | **원가통계비목 목록** · 전체 지우기 |

집행률 색: 보라(정상) → **주황**(80% 이상) → **빨강**(100% 이상), 완료는 회색.

### AI에게 묻기 (예산 창 아래)

AI가 연결되어 있으면 지금 예산 표를 보고 답합니다. 예산 데이터는 **AI가 직접 고치지 않습니다.**

- **질문**: "교육운영비 전체에서 얼마 남았어?", "남은 50만원으로 간식비 쓸 수 있는 항목은?" 처럼 적고 Enter.
- **빠른 질문 버튼**: 초과 집행 항목 · 잔액 많은 순 · 비목별 요약 · 남은 돈 점검 (회계연도 3월~2월 기준).
- **말로 지출 입력**: "교과융합캠프 간식비 5만원 썼어"라고 적으면, AI가 항목을 찾아 「이번에 쓴 금액으로 넣을까요?」와 바뀔 집행액·잔액을 보여 줍니다. **[넣기]**를 눌러야 반영되고, 항목이 애매하면 AI가 되묻습니다. 완료한 항목에는 넣지 않습니다.
- 쓴 곳도 함께 말하면 사용 내역에 남습니다. 예: "체육대회 협의회비에 15만원 썼어" → 미리보기의 괄호 안에 「체육대회 협의회비」가 보입니다.
- 쓴 곳도 함께 말하면 사용 내역에 남습니다. 예: "체육대회 협의회비에 15만원 썼어" → 미리보기의 괄호 안에 「체육대회 협의회비」가 보입니다.
- 바로 앞 질문 두 개까지 이어서 물을 수 있습니다 ("그중에 제일 큰 건?").
- 개인정보 보호 모드가 켜져 있으면 보내는 글의 개인정보를 가립니다.

### 예산 AI에게 지시하기 (잔액 맞추기, 되돌리기)

목표 금액을 말하면 AI가 항목을 찾고, 집행액과 잔액 계산은 앱이 합니다.

- **잔액 맞추기**: "협의회비 잔액 30만원으로 맞춰줘" → 잔액이 30만원이 되도록 집행액을 계산해 보여 줍니다.
- **집행액 고치기**: "간식비 집행액을 12만원으로 고쳐줘" → 집행액을 12만원으로 바꿉니다.
- **쓴 돈 넣기**: "간식 5만원 썼어" → 집행액에 5만원을 더합니다 (기존 기능).

보여 주는 표: 산출내역 · 세부항목 · 집행액(기존 → 변경) · 잔액(기존 → 변경). 아래에 「실제 집행 내역과 맞는지 확인하세요.」라고 나옵니다.

- **[넣기]**를 눌러야 반영됩니다. **[취소]**하면 아무것도 바뀌지 않습니다.
- 말한 금액이 예산보다 크거나, 완료한 항목이거나, 없는 항목이면 그 제안만 빠지고 회색 줄로 이유가 적힙니다.
- 항목이 애매하면 AI가 되묻습니다. 그때는 아무것도 바꾸지 않습니다.
- **[넣기] 직후 [되돌리기]** 버튼이 나옵니다. 바로 전에 넣은 변경을 넣기 전 집행액으로 되돌립니다 (가장 최근 1회분만).
- 입력칸 예: 「예: 협의회비 잔액 30만원으로 맞춰줘」

### 예산 화면 캡처를 붙여넣어 정리하기

1. 학교 예산 시스템에서 **세부항목 · 원가통계비목 · 산출내역 · 예산현액 · 예산잔액**이 보이게 표를 캡처합니다 (Win+Shift+S 등).
2. 예산 창에서 **우클릭 → 붙여넣기** 또는 **Ctrl+V**. (이미지 파일을 창에 끌어다 놓아도 됩니다.)
3. 세부항목별로 나뉜 **확인 화면**이 뜹니다. 칸을 두 번 눌러 고칠 수 있고(세부항목 이름도), **노란 줄**은 숫자를 다시 확인해 주세요.
4. 가져오기 방식을 고르고 [가져오기]:
   - **같은 이름의 세부항목은 새 내용으로 바꾸고, 나머지는 추가** (추천 — 같은 화면을 다시 캡처해 갱신할 때)
   - 지금 있는 내용은 그대로 두고 모두 추가 / 지금 있는 예산을 모두 지우고 교체

- 세부항목 칸은 묶음의 첫 줄에만 있으므로, 새 이름이 나올 때까지 아래 줄은 같은 세부항목으로 묶습니다.
- 화면에는 집행액이 없으므로 **집행액 = 예산현액 − 예산잔액**으로 계산합니다 (잔액이 마이너스면 초과 집행).
- 읽는 방법: AI가 연결되어 있으면 AI가 이미지를 읽습니다. **개인정보 보호 모드**가 켜져 있으면 PC(Windows 글자 인식)에서 읽은 글자만 AI에 보냅니다. AI가 없으면 PC 글자 인식만으로 정리하는데, 이때는 숫자를 꼭 확인하세요.
- 칸이 좁아 잘린 세부항목 이름(예: 「…선택과목」)은 확인 화면에서 고쳐 주세요.
- **원가통계비목**은 [⋯] → 원가통계비목 목록과 지금 예산에 쓰이는 비목을 기준으로, 한두 글자 틀리게 읽은 것을 바로잡습니다(예: 교육운염비 → 교육운영비). 고친 줄과 목록에 없는 비목은 노란색으로 알려 줍니다. 목록은 항목을 직접 입력할 때 원가통계비목 칸에서도 고를 수 있습니다.

엑셀 파일(.xls/.xlsx)은 창에 끌어다 놓거나 [가져오기] → 엑셀 파일 열기, 엑셀에서 복사한 셀 범위는 Ctrl+V로도 가져옵니다.

## 17. 업데이트

- **자동 업데이트**(기본 켬) — 새 버전이 나오면 앱이 뒤에서 조용히 받아 둡니다. 그다음 **트레이 → 종료로 앱을 끌 때** 또는 **다음에 켤 때** 화면 없이 설치합니다. 켤 때 설치하면 10초쯤 뒤 다시 켜지고, 제목 표시줄에 「✨ v○.○○로 업데이트됐어요」가 잠깐 보입니다. 누를 버튼은 없습니다.
- 바로 받고 싶으면 메뉴 **도움말 → 업데이트 확인 → [지금 업데이트]** 한 번.
- 자동으로 하기 싫으면 메뉴 **설정 → 자동 업데이트**를 끄세요. 그러면 새 버전 알림만 한 번 뜹니다.
- **안전장치:** 이 앱의 GitHub 릴리스에서 받은 설치 파일만 쓰고, 확인값(SHA256)이 맞지 않으면 설치하지 않습니다(설치 직전에도 다시 확인). 두 번 연속 설치에 실패하면 자동 설치를 멈추고 알려 줍니다.
- 설치 위치는 내 사용자 폴더(`%LOCALAPPDATA%\Programs\SSNnote`)라서 관리자 확인(UAC) 창이 뜨지 않습니다. v2.82 이하에서 처음 옮겨 올 때만 예전 위치(Program Files)의 프로그램을 지우느라 UAC가 한 번 뜹니다.
- 학교 컴퓨터에서는 방화벽 때문에 처음 한 번은 막히고 두 번째에 될 때가 있습니다.
- 메모·업무·설정은 업데이트해도 그대로 남습니다.

## 18. 자주 묻는 질문

**Q. 데이터는 어디에 저장되나요?**
PC의 `%APPDATA%\SSNnote\` 폴더(`ssnnote.db`)에 저장됩니다. 다른 PC로 옮기려면 서서니 노트를 끈 뒤 이 폴더를 통째로 복사하세요. API 키는 그 PC의 Windows 계정으로만 풀리게 암호화되어 있어서, **다른 PC에서는 키를 다시 입력**해야 합니다.

**Q. AI를 쓰면 공문 내용이 밖으로 나가나요?**
AI를 쓰는 순간 그 내용이 선택한 AI 회사로 전송됩니다. 개인정보 보호 모드를 켜 두세요. OpenCode의 추천 모델 claude-haiku-5-5는 학습에 쓰이지 않습니다(30일 보관 뒤 삭제). Claude·ChatGPT API도 기본적으로 보낸 내용을 학습에 쓰지 않습니다.

**Q. 캡처했는데 "Windows OCR을 쓸 수 없어 글자를 읽지 못했습니다"가 떠요.**
개인정보 보호 모드에서는 PC의 Windows OCR로 글자를 먼저 읽습니다. Windows 설정에 **한국어 언어 팩**이 설치되어 있는지 확인하거나, 보호 모드를 끄면 이미지로 분석합니다(🖼 표시 모델 필요).

**Q. 노트북(작은 화면)에서 창이 화면 밖으로 나가거나 글자가 잘려요.**
서서니 노트는 Windows 배율(125%·150% 등)에 맞는 크기로 글씨를 선명하게 그리고, 칸·버튼 폭을 글자 크기에 맞추며, 큰 모니터에서 쓰던 창도 지금 화면 안에 들어오게 크기와 위치를 맞춥니다. 그래도 창이 크게 느껴지면 메뉴 → 배경색·글자 크기 → **글자 크기**로 줄이세요.

**Q. 단축키가 안 먹어요.**
다른 프로그램이 같은 단축키를 쓰고 있을 수 있습니다. 메뉴로도 같은 기능을 쓸 수 있습니다. 메뉴 → 설정 → 단축키 사용이 켜져 있는지도 확인하세요.

**Q. 앱이 두 번 실행되지 않아요.**
서서니 노트는 한 번에 하나만 실행됩니다. 이미 트레이에서 실행 중이면 **Ctrl+Shift+E**로 불러오세요.

**Q. 실수로 업무를 지웠어요.**
아래쪽 **지난 기록** 버튼 → **지난 업무** 칸에서 「되살리기」를 누르세요. (마감이 지나지 않은 업무만 되살릴 수 있어요.)
