## 1. 처음 시작하기

1. [릴리스 페이지](https://github.com/justkevin2570-hash/SSNnote/releases/latest)에서 `SSNnote_Setup.exe`를 받아 설치합니다.
2. 바탕화면에 노란 메모장이 뜹니다. 맨 위 **업무명** 칸에 할 일을 쓰고 **Enter**를 누르면 업무가 추가됩니다.
3. 마감일이 있으면 업무명 아래 **마감일** 칸에서 날짜(필요하면 시각)를 고른 뒤 Enter를 누르세요.
4. 앱을 닫아도 작업 표시줄 오른쪽 **트레이 아이콘**으로 계속 실행됩니다. 완전히 끄려면 트레이 아이콘 → **종료**.

> 다른 창에서 일하다가 **Ctrl+Shift+E**를 누르면 서서니 노트가 바로 앞으로 나옵니다.

## 2. 화면 구성

**제목 표시줄 (맨 위)**

| 버튼 | 하는 일 |
|---|---|
| ₩ | 예산 관리 창 열기 |
| ✏️ (연필) | 메모 모드 ↔ 업무 모드 전환 |
| … | 메뉴 |
| 📌 | 항상 화면 위에 고정 켜기/끄기 (Ctrl+Shift+F) |
| ✕ | 메모장 닫기 (앱은 트레이에서 계속 실행) |

**입력 칸** — 업무명, 마감일, 시각, 반복(반복 없음·매주·격주·매월·매년·사용자 설정)

**업무 목록** — 별(중요), 업무명, D-day, ⋮(업무 메뉴)

**아래쪽 버튼**

| 버튼 | 하는 일 |
|---|---|
| 달력 | 월간 달력 (모든 메모장의 마감 업무) |
| 공문 작성 (AI) | 공문 작성 창 |
| 저장 기록 | 공문 작성 창에서 저장한 공문 목록 |
| 지난 기록 | 삭제한 업무 기록 (복원 가능) |

## 3. 업무 관리

### 업무 추가
- **업무명** 칸에 쓰고 **Enter**. **Tab**을 누르면 마감일 → 시각 → 반복 칸으로 차례로 이동합니다.
- 마감일을 비워 두면 날짜 없는 업무가 됩니다. 나중에 업무 줄의 **「+날짜」**를 눌러 넣을 수 있습니다.
- **반복**을 고르면 마감이 지난 다음 날 자동으로 다음 마감일로 넘어갑니다. 「사용자 설정…」으로 "매월 둘째 주 화요일" 같은 반복도 만들 수 있습니다.

### 업무 다루기

| 하고 싶은 일 | 방법 |
|---|---|
| 업무명 고치기 | 업무를 더블 클릭, 또는 선택하고 **F2** |
| 업무 사이 이동 | 업무를 선택하고 **↑ / ↓** |
| 업무 메모 열기 | 업무를 선택하고 **Enter**, 또는 업무명 옆 ▼ |
| 메모 닫기 | 메모 칸에서 **Esc** 또는 **Ctrl+Enter** |
| 중요 표시 | 업무 앞 **☆**를 눌러 ★로 |
| 완료 표시 (가운데 선) | ⋮ 메뉴 → 가운데 선 (메뉴를 연 상태에서 **C**) |
| 삭제 | ⋮ 메뉴 → 삭제 (메뉴를 연 상태에서 **Delete** / **D**). 지난 기록에 남음 |
| 반복 바꾸기 | ⋮ 메뉴에서 반복 선택 |

### 업무 메모
업무를 펼치면 아래에 메모 칸이 열립니다.
- **메모** — 자유롭게 적습니다.
- **관련 공문번호** — 직접 쓰거나 **[스크린샷]**을 눌러 화면의 공문번호를 찍으면 글자로 읽어 넣습니다. **[복사]**로 복사합니다.
- **붙임파일** — 파일을 업무 줄로 끌어다 놓으면 붙습니다. 누르면 파일이 열립니다.

### D-day 표시
마감까지 남은 날을 `D-3`처럼, 오늘이면 `D-day`, 지났으면 `기한 지남(D+2)`으로 보여줍니다. 가까운 마감은 빨간 글씨입니다.

## 4. 마감 알림

메뉴 **⚙️ 설정 → 마감 알림**에서 고릅니다.
- **D-day 5일 이내 알림** — 마감 5일 이내 업무를 정해진 간격(30분 / 1시간 / 3시간 / 사용자 설정)마다 알려줍니다. 「사용 안 함」으로 끌 수 있습니다.
- **당일 마감 3시간 전부터 알림** — 시각이 있는 오늘 마감 업무를 3시간·2시간·1시간·30분 전에 알려줍니다.

---

## 5. 오늘 한눈에 보기

메뉴 **📋 오늘 한눈에 보기**. 하루 한 번 앱을 켤 때 자동으로도 뜹니다(창 아래 체크로 끌 수 있음).
- 지난 마감 · 오늘 마감 · 이번 주(7일) · 공문 업무 개수와 한 줄 요약
- 급한 업무 목록 — 누르면 해당 메모장에서 그 업무가 반짝 강조됩니다.
- 예산 집행률 막대 (예산을 등록한 경우). 100%를 넘으면 빨간색.

## 6. 빠른 찾기 (Ctrl+K)

기능과 업무를 이름으로 찾아 바로 엽니다.
- **초성 검색**이 됩니다: `ㅇㅅ` → 예산 관리, `ㄱㅁㅎㅇ` → 교무회의 자료 제출
- 띄어쓰기는 무시하고, 영어(budget, capture …)로도 찾을 수 있습니다.
- **↑↓**로 고르고 **Enter**로 실행, **Esc**로 닫기.
- 업무를 고르면 해당 메모장에서 그 업무를 강조합니다.

## 7. 달력

아래쪽 **[달력]** 버튼.
- 모든 메모장의 마감 업무를 날짜 칸에 보여줍니다. **◀ ▶**로 달을 넘기고 **[오늘]**로 돌아옵니다.
- 날짜를 누르면 그날 업무를 보고 **편집 / 삭제**, **＋ 일정 추가**를 할 수 있습니다.

## 8. 메모 모드와 여러 메모장

- **메모 모드** — 제목 표시줄의 ✏️ 버튼을 누르면 업무 목록 대신 자유 메모장이 됩니다. 한 번 더 누르면 돌아옵니다.
- **새 메모장** — 메뉴 → 🆕 새 메모장. 회의 메모, 연락처처럼 따로 두고 싶은 내용에 좋습니다.
- **꾸미기** — 메뉴 → 🎨 이 메모장 → 배경색 / 글자 크기 / 줄 간격 (이 메모장에만 적용)
- **창 붙이기** — 메모장을 다른 메모장 옆으로 끌면 자석처럼 붙습니다. 나란히 붙었을 때 나타나는 버튼을 누르면 하나처럼 함께 움직이게 묶이고, 다시 누르면 풀립니다.
- **접기** — **Ctrl+Shift+R**을 누르면 제목 표시줄만 남기고 접힙니다. 한 번 더 누르면 펼쳐집니다.
- **메모장 삭제** — 메뉴 → 🗑️ 메모장 삭제 (첫 메모장은 지울 수 없음). 그 메모장의 업무도 함께 지워집니다.

## 9. AI 연결 (API 키)

AI 공문 캡처, 자동 초안, 공문 작성 창의 AI 대화에 쓸 AI를 고릅니다.
메뉴 **⚙️ 설정 → AI 연결 (API 키)…** (공문 작성 창의 **[AI 설정]** 버튼과 같음)

지원하는 AI: **OpenCode**, Claude, ChatGPT, Gemini, NVIDIA, 내부 AI(Ollama, PC 안에서 실행). 각 회사에서 API 키를 받아 넣습니다. API는 쓴 만큼 요금이 나가며, 공문 한 건은 보통 몇 원 수준입니다.

### OpenCode 연결하기
1. **OpenCode** → 요금제 선택: **OpenCode Go (월 구독)** 또는 **OpenCode Zen (충전식)**
2. **API 키** 입력 — 「저장」을 끄면 앱을 끌 때 지워집니다(공용 PC 권장).
3. **모델 선택** — OpenCode에서 받은 최신 목록이 나옵니다.
   - **🖼 이미지** 표시가 있는 모델은 캡처한 공문 이미지도 직접 읽습니다.
   - **⚠ 지역 설정 필요**(DeepSeek) — OpenCode 기본 설정(유럽·미국)에서는 막혀 있습니다. 쓰지 않는 것을 권장합니다.
   - 추천: **kimi-k3** (기본값) 또는 **claude-haiku-5-5** (빠르고 저렴, 서식을 잘 지킴. 단 30일 보관)
4. 자동으로 **연결 확인**을 합니다. 성공하면 창 아래 상태 표시줄에 「OpenCode · 모델이름 연결 완료.」가 뜹니다(별도 창은 뜨지 않음). 실패하면 이유를 알려주고 설정을 바꾸지 않습니다.

## 10. AI 공문 캡처 (Ctrl+Shift+X)

공문을 화면에서 캡처하면 AI가 읽고 정리해 줍니다. (먼저 [AI 연결](#9-ai-연결-api-키)이 필요합니다.)

1. 공문 화면을 띄우고 **Ctrl+Shift+X** (또는 메뉴 → 📸 AI 공문 캡처)
2. 마우스로 공문 부분을 드래그합니다.
3. 결과 창에 **업무명, 기한(시각), 공문번호, 발신, 시행일, 요약, 할 일, 붙임**이 채워집니다. 틀린 곳은 고칠 수 있습니다.
4. 버튼을 고릅니다.
   - **업무로 등록** — 마감일·공문번호·메모(요약·할 일·붙임)까지 넣어 업무 목록에 추가
   - **✉ 회신 공문 작성** — 공문 작성 창에 회신 제목과 '관련: 공문번호(날짜)'를 채우고 AI가 본문 초안 작성
   - **요약 복사** / **원문 복사** / **다시 분석**

> AI가 실패해도 칸을 직접 채워 업무로 등록할 수 있습니다.
> 공문 작성 창이 앞에 떠 있을 때 Ctrl+Shift+X를 누르면, 그 창의 제목·관련번호 칸으로 캡처합니다.

## 11. 공문 작성 (AI)

아래쪽 **[공문 작성 (AI)]** 버튼.

| 칸·버튼 | 하는 일 |
|---|---|
| 공문 제목 | 제목을 쓰고 **Enter** → 자동 초안 생성 |
| 관련 번호 | 관련 공문번호. ↑ 버튼은 이 칸의 글을 제목으로 옮김 |
| 붙임 개수 | 초안의 붙임 줄 개수 |
| 자동 초안 생성 | 공문 종류(계획·구매·제출·안내 등)에 맞는 뼈대를 넣고 AI가 내용을 채움 |
| AI에게 요청 (아래 칸) | "장소를 시청각실로 바꿔줘"처럼 요청 → AI가 본문을 고침. **Enter** 보내기, **Shift+Enter** 줄바꿈, **Esc** 취소 |
| 제목 복사 / 본문 복사 | 업무관리시스템에 붙여 넣기용 |
| 저장 후 나가기 | 공문을 **저장 기록**에 남기고 닫기 |

- AI가 고친 뒤 **Ctrl+Z**를 누르면 이전 내용으로 돌아갑니다(**Ctrl+Y**로 다시 AI 결과).
- AI 오류·빈 답·취소 때는 작성 중이던 내용이 그대로 남습니다.
- [학교 정보](#12-학교-정보와-개인정보-보호)를 저장해 두면 초안에 학교명·부서·담당자가 반영됩니다.
- AI 대화는 본문을 AI 답으로 **바꿉니다**. 질문만 하고 싶을 때는 Ctrl+Z로 되돌리세요.

## 12. 학교 정보와 개인정보 보호

메뉴 **⚙️ 설정 → 학교 정보 설정…**

- **학교 정보** — 학교명, 부서, 담당자, 직위, 연락처, 결재 라인, 자주 쓰는 붙임. 공문 초안과 회신 공문에 자동으로 들어갑니다.
- **개인정보 보호 모드** (기본 켬, 메뉴에서도 켜고 끔) — 외부 AI로 보내기 전에 **주민등록번호, 전화번호, 이메일, 아래에 등록한 이름**을 가립니다(예: `010-****-5678`, `김○○`).
  - 캡처한 공문은 이미지 대신 **PC에서 읽은 글자만** 보냅니다.
  - 학교 연락처와 담당자 본인 이름은 가리지 않습니다.
  - **등록하지 않은 이름은 가리지 못합니다.** 학생 명단이 들어간 공문이라면 이름을 등록해 두세요.
  - PC 안에서 도는 AI(Ollama)에는 적용하지 않습니다.

## 13. Claude 연결

Claude 구독(Pro·Max)이 있으면, **Claude 앱에서** 서서니 노트의 업무를 보고 추가하고 공문 초안을 쓸 수 있습니다. API 키는 필요 없습니다.

1. Claude 데스크톱 앱이나 Claude Code를 설치하고 로그인합니다.
2. 메뉴 **⚙️ 설정 → Claude 연결…** → 쓰는 쪽의 **[연결]**
3. Claude 데스크톱 앱은 **완전히 종료(트레이 아이콘까지)했다가 다시 켜면** 적용됩니다.

Claude에게 이렇게 말해 보세요.
- "오늘 할 일 정리해줘", "이번 주 마감 뭐 있어?"
- "다음 주 금요일 5시까지 교과협의회 계획서 제출, 업무로 넣어줘"
- "교무회의 자료 제출 완료 처리해줘"
- "학교폭력 실태조사 결과 보고 공문 초안 써줘"

추가·수정한 업무는 켜져 있는 메모장에 3초 안에 나타납니다. Claude는 업무를 **삭제할 수 없습니다**(실수 방지).

> Claude 앱에 공문 캡처 이미지를 붙여 넣고 "이 공문 업무로 등록해줘"라고 해도 됩니다.

자세한 내용: [Claude 연결 방법](../Claude_연결_방법.md)

## 14. 예산 관리

제목 표시줄의 **₩** 버튼.

- **예산 등록·관리** — 예산 항목(사업)과 세부 항목을 만들고 고칩니다.
- **엑셀 가져오기** — 사업관리카드(예산) 엑셀 파일(.xls/.xlsx)을 창에 **끌어다 놓거나**, 엑셀에서 셀을 복사해 **Ctrl+V**로 붙여 넣습니다.
- **집행액** — 칸에 입력하고 Enter. 편성액·집행액·잔액·집행률이 바로 계산됩니다.
- **완료** — 다 쓴 항목은 완료 표시(취소선), 「완료 취소」로 되돌림.
- 위쪽 탭으로 사업별 보기 / **전체 보기**, **초기화**로 전부 지우기.

## 16. 단축키 모음

| **Ctrl+Shift+R** | 접기/펼치기 |
| **Tab** | 입력 칸 사이 이동 |
| **F2** | 선택한 업무명 고치기 |

| 단축키 | 하는 일 |

## 18. 자주 묻는 질문

**Q. 데이터는 어디에 저장되나요?**
PC의 `%APPDATA%\SSNnote\` 폴더(`ssnnote.db`)에 저장됩니다. 다른 PC로 옮기려면 서서니 노트를 끈 뒤 이 폴더를 통째로 복사하세요. API 키는 그 PC의 Windows 계정으로만 풀리게 암호화되어 있어서, **다른 PC에서는 키를 다시 입력**해야 합니다.

**Q. AI를 쓰면 공문 내용이 밖으로 나가나요?**
AI를 쓰는 순간 그 내용이 선택한 AI 회사로 전송됩니다. 개인정보 보호 모드를 켜 두고, 학생 이름은 학교 정보 설정에 등록해 두세요. OpenCode의 추천 모델(kimi-k3 등)은 학습에 쓰지 않고 보관하지 않습니다(claude-haiku-5-5는 30일 보관).

**Q. 캡처했는데 "Windows OCR을 쓸 수 없어 글자를 읽지 못했습니다"가 떠요.**
개인정보 보호 모드에서는 PC의 Windows OCR로 글자를 먼저 읽습니다. Windows 설정에 **한국어 언어 팩**이 설치되어 있는지 확인하거나, 보호 모드를 끄면 이미지로 분석합니다(🖼 표시 모델 필요).

**Q. 단축키가 안 먹어요.**
다른 프로그램이 같은 단축키를 쓰고 있을 수 있습니다. 메뉴로도 같은 기능을 쓸 수 있습니다. 메뉴 → ⚙️ 설정 → 단축키 사용이 켜져 있는지도 확인하세요.

**Q. 앱이 두 번 실행되지 않아요.**
서서니 노트는 한 번에 하나만 실행됩니다. 이미 트레이에서 실행 중이면 **Ctrl+Shift+E**로 불러오세요.

**Q. 실수로 업무를 지웠어요.**
아래쪽 **[지난 기록]**에서 복원할 수 있습니다.
